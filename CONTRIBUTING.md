# Contributing

Thank you for improving AI Whiteboard Assistant.

1. Create a focused branch from the latest `main`.
2. Keep changes modular and preserve existing whiteboard behavior.
3. Never commit `.env`, API keys, tokens, private boards, or generated test artifacts.
4. Run frontend lint, unit tests, build, and Playwright E2E.
5. Run backend tests, typecheck, and build.
6. Open a pull request describing the user impact and validation performed.

Use Mock AI for tests and contributions. A real OpenAI request must never be required by CI.
